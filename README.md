# VAW Media Map — National Media Intelligence & Incident Tracker

An interactive, AI-driven spatial mapping platform that tracks, aggregates, and visualizes incidents of Violence Against Women (VAW) reported exclusively by verified national mainstream media. 

The platform turns global and regional maps "red" dynamically over time to provide clear visual data on incident velocity, geographic density, and systemic safety trends.

---

## 🌟 Key Features

- **Dynamic Chronological Time-Slider:** Playback engine with variable speeds ($1\times, 2\times, 5\times$) visualizing how reported incidents accumulate over custom date ranges.
- **Strict Media Whitelisting:** Limits data ingestion strictly to credible, national news publishers to maintain baseline authenticity.
- **AI-Powered Event Structuring:** Automatically parses news RSS feeds and articles using Gemini API to extract structured locations, dates, categories, and summaries.
- **Hierarchical Spatial Zoom:** Smoothly transitions from aggregated continental counts down to district-level heatmaps and localized incident nodes.
- **Interactive Analytics Drawer:** Filter by incident type (Femicide, Domestic Abuse, Harassment, Cyber-violence) and access direct primary source article links.
